## Product docs

Stories, epics, open decisions, ADRs, tenets and architecture in `docs/` follow the `po` skill
(https://github.com/martint17r/po-skill): load it before changing `docs/epics.md`,
`docs/decisions-open.md`, `docs/adr/`, `docs/tenets.md` or `docs/architecture.md`,
review code changes against the tenets, and run its docs-only check before a docs PR.
